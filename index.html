Search Towers

Search anything you know about a tower. Tap Add/Edit Info on any result to open that exact tower and add missing data. Matches can come from tower name, carrier, PLMN, LTE/5G, eNB/gNB, Cell ID/NCI, sector/local cell, PCI, TAC, band, bandwidth, status, notes, coordinates, or verification state. Numeric searches also run LTE /256 and 5G /4096 math.

Uses the tower’s current status, including pending Add/Edit changes. Naming is handled separately by “Unnamed only.”

CellMapper Tower Lookup

Enter the carrier, network type, and eNB/gNB. The app builds the correct CellMapper map for that carrier. Use 4G LTE for eNB searches, 3G UMTS for NodeB searches, and 5G NR for gNB searches.
If a scanned tower is not already in your Registry, the app will simply ask whether you want to add it.

CellMapper Verified Autofill

Tower Registry can check CellMapper in the background using the selected carrier, LTE/3G/5G, and tower ID. Green verified towers can automatically fill the tower ID and coordinates into Add/Edit.
CellMapper status: Green = Verified, red = Unverified, and no matching tower = Not in CellMapper.

Screenshot Auto-Identify

Choose a cellular diagnostic screenshot. The app automatically reads PLMN, LTE/5G, Cell ID/NCI, band, bandwidth, PCI, TAC and signal values from the picture, then identifies the tower.

Tap here, then choose Paste to paste a copied photo
Review before using. OCR can misread 0/O, 1/I and minus signs. The scanner now reads the number/value inside the same horizontal line band as each label. TAC, PCI, PLMN and Cell ID/NCI stay in their own rows.

Tower Map

Saved tower coordinates appear as pins. Use the map control to switch between Street Map and Satellite imagery. Tap a pin to view the tower, or edit a tower to add coordinates.

Map pin colors: ● T-Mobile · ● AT&T · ● Verizon · ● STRATA · ● Union

Set / Move Tower Location by eNB/gNB

Enter an eNB or gNB, then paste coordinates such as 40.455500, -109.528700. The matching tower will be updated without opening Add/Edit.

This tool previews a new tower location first. Nothing changes permanently until you tap Save Location.

Place / Drag Tower

Enter an eNB or gNB, then choose the tower. Tap the map to move it, or drag its pin to fine-tune the location. Changes save immediately.

Add Tower

Type an existing eNB/gNB and the app will autofill all saved details. If a scan or lookup finds an unknown ID, the app can open this form with everything it already knows prefilled. Future carriers are also supported.
