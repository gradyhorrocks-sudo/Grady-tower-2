Choose a screenshot from a cellular diagnostic app. Optimized for your diagnostic screen: each label and value are paired when they fall inside the same horizontal row between the same separator lines. The scanner then reads the value to the right of that label.

Review before using. OCR can misread 0/O, 1/I and minus signs. The scanner now reads the number/value inside the same horizontal line band as each label. TAC, PCI, PLMN and Cell ID/NCI stay in their own rows.
